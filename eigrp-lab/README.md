# EIGRP для IPv4 — лабораторная работа

- **EIGRP_AS10_final.pkt** — итоговый проект для Cisco Packet Tracer.
- **EIGRP_solution.zip** — весь комплект с итоговым и двумя промежуточными проектами, конфигурациями, отчётом и результатами статической проверки.
- **EIGRP_report_RU.docx** — редактируемый отчёт на русском.
- **EIGRP_report_RU.pdf** — отчёт в PDF.

Скачайте проект и откройте его в Cisco Packet Tracer через **File → Open**.
В проект записаны три Cisco 1841 с WIC-2T, три ПК, соединения, адресация, EIGRP AS 10, bandwidth и passive-interface.
LAN-интерфейс — FastEthernet0/0 вместо GigabitEthernet0/0, что допускается заданием для других моделей.
Для прямых соединений PC–1841 использован crossover вместо указанного в задании straight-through; это отклонение нужно учитывать при сдаче.

Учебные пароли: консоль — `cisco`, команда `enable` — `class`.

**Границы проверки:** проект сформирован программно в формате 8.2.0.0162 и прошёл независимую статическую проверку структуры и конфигураций.
Открытие в Cisco Packet Tracer 9.0.1, установление соседств и реальные ping в среде подготовки не выполнялись.
Реальные скриншоты не созданы; перед сдачей заполните ФИО/группу и добавьте результаты из приложения в отчёт.
