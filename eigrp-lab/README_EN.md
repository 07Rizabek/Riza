Open the `.pkt` project in Cisco Packet Tracer using **File → Open**. It contains three Cisco 1841 routers with WIC-2T modules, three PCs, IPv4 addressing, EIGRP AS 10, final bandwidth values, and passive LAN interfaces.

The LAN interface is `FastEthernet0/0` instead of `GigabitEthernet0/0`; the assignment permits adapting interface names to the router model. Direct PC-to-1841 connections use crossover cables rather than the specified straight-through cables. This cable-type deviation is documented in the report.

Classroom passwords: console/VTY `cisco`; privileged EXEC (`enable`) `class`.
